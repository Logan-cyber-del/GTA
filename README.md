# GTA — Chaos Car

Prototipo 3D arcade para Unity 6000.0.23f1.

## Contenido inicial
- Coche con conducción física
- Cámara dinámica
- Policía perseguidora
- Pinchos que dañan el coche
- Rampas, nitro y sistema de puntuación
- Reinicio de partida

## Preparación
1. Abrir Unity Hub y crear un proyecto 3D Core llamado `GTA` con Unity 6000.0.23f1.
2. Copiar la carpeta `Assets` de este repositorio a la raíz del proyecto.
3. Abrir `Scenes/ChaosCity` y presionar Play.

## Controles
- W/S o flechas arriba/abajo: acelerar/frenar
- A/D o flechas izquierda/derecha: girar
- Espacio: freno de mano
- Shift izquierdo: nitro
- R: reiniciar
